# Plan de inspección

## Alcance

El Kindle montado por USB es una fuente estrictamente de solo lectura. Los
inventarios y análisis se guardan únicamente en este repositorio, y los datos
privados o temporales permanecen bajo `work/`, fuera del control de versiones.

## Etapas

1. Confirmar dispositivo y punto de montaje.
2. Crear un inventario reproducible de rutas y formatos.
3. Inspeccionar la estructura de muestras representativas de directorios `.sdr`.
4. Inspeccionar únicamente los esquemas de las bases de datos relevantes.
5. Analizar el formato de `My Clippings.txt` con muestras mínimas.
6. Investigar dónde se exponen —si se exponen— las colecciones.
7. Documentar fuentes, confiabilidad y limitaciones de cada dato.
8. Diseñar el extractor después de comprender los datos disponibles.
