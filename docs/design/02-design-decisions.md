# Decisiones del sistema visual

## Principios

1. Leer y explorar antes que configurar.
2. Las acciones infrecuentes permanecen plegadas o en páginas de ajustes.
3. Las referencias técnicas existen, pero no dominan la lectura.
4. Una sola estructura HTML responde a escritorio y móvil.
5. Ningún estado visual promete una función inexistente.

## Sistema

- Fondo: marfil `#fbf8f3`; superficie: blanco cálido `#fffdf9`.
- Tinta: `#23201d`; texto secundario: `#6b655d`.
- Acción primaria: terracota `#923824`; confirmación: verde `#365943`.
- Títulos y citas: Georgia como serif local y Newsreader cuando esté disponible.
- Interfaz: system-ui; no se depende de fuentes o iconos remotos.
- Medida de lectura: máximo aproximado de 70 caracteres.
- Foco: contorno visible de 3 px; controles táctiles de al menos 44 px.
- Radio pequeño y sombras escasas para conservar el carácter editorial.

## Responsive

Desde 960 px se habilitan composiciones de dos columnas. Debajo de 760 px la
navegación principal se convierte en barra inferior y las grillas se apilan o
usan dos columnas solo cuando una portada conserva legibilidad suficiente.
